# 鱼渔

鱼渔是一款适合手机、平板和电脑使用的解题陪练网页。孩子可以说题、打字或上传照片。图片和语音先由百炼千问转成文字，孩子核对后再提交。每轮给一个小任务，并标明该填数字、算式、几个字还是一句话。

## 本地运行

需要 Node.js 20 或更新版本。在此目录运行 `YUYU_STATE_DIRECTORY=./family-data node server.mjs`，打开 `http://127.0.0.1:3731/`。家庭登录 Cookie 要求 HTTPS，浏览器录音也要求安全上下文和麦克风权限。没有百炼密钥时可以使用三道内置练习。

从运行环境注入 `DASHSCOPE_API_KEY` 来启用模型功能。解题默认使用 `qwen3-vl-plus`，可通过 `DASHSCOPE_MODEL` 覆盖。转写使用 `qwen-audio-3.1-asr-flash`，朗读使用 `qwen3-tts-flash`。若使用业务空间专属域名，将该空间的 OpenAI 兼容基础地址设置为 `DASHSCOPE_BASE`，地址不含 `/chat/completions`。

## ECS 部署

当前站点使用 `/yuyu/` 路由，通过现有 Nginx 的 HTTPS 网关转发到 `127.0.0.1:3731`。服务名为 `yuyu.service`。部署脚本针对这台 ECS 的目录和网关配置编写。在其他主机使用时，需要按实际路径调整 `ops/install.sh`、服务单元和网关配置。

服务从受限文件 `/etc/yuyu/model.env` 读取百炼配置。更新配置后可在 ECS 上执行 `systemctl restart yuyu.service`。健康检查路径为 `/yuyu/api/health`。家庭记录由 systemd 的 `StateDirectory=yuyu` 持久化，备份时需要同时保护这个目录和模型配置。

## 提示与数据

数学辅导默认面向浙江杭州小学四年级、九岁孩子。模型按题型优先用四则运算、数位格、分级、算盘和日常物件；每轮只呈现一个小任务。独立审查会检查适龄、无直接答案及孩子提交内容的正确性，必要时重写提示。模型仍可能读错图或误判过程。

新开的题目若匹配已经核验的分步路线，会逐步检查数字、算式或提问。答错或求提示时留在当前步骤，后续任务从已确认的结果接着走。覆盖情况和通关条件见评测报告。

游客的题目本和贝壳保存在当前浏览器的 IndexedDB 中。创建或登录同一个家庭账号后，可跨设备同步题目、解题记录、继续进度和贝壳。旧设备可主动导入已有记录，已经同步过的题目不会重复计奖。账号使用账号名和密码，无邮箱或手机号找回功能。

解题进度最近活动后 30 天内可原地继续，过期后可以查看已有步骤并重做。轮换服务端模型密钥会使未完成题的解题进度需重新开始。登录家庭账号时，服务端会保存文字题目、对话和贝壳；题图和录音不写入鱼渔存储。题目、尝试、题图、录音与要朗读的文本会发送给百炼处理。
